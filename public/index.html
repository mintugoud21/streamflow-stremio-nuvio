1. Stremio Desktop & Mobile App

Click the "Install to Stremio" button above. Your browser will prompt you to open Stremio, where you simply click "Install".

2. Stremio Web or Android TV

Copy the Stremio Manifest URL using the Copy URL button above. Open Stremio, go to Addons (puzzle icon) > search bar / Addon URL box > paste the URL and confirm.

1. URL Import in Nuvio

Copy the Nuvio Plugin URL using Copy JSON URL above. In Nuvio, navigate to Settings / Plugins > Add by URL > paste the link.

2. Offline .JSON Plugin File

Click "Download .JSON Plugin" above to save nuvio-streamflow-plugin.json. In Nuvio, choose Import Plugin from File and upload the saved file.

Standard Stremio Addon Protocol v3 and Nuvio Plugin endpoints: 

GET /manifest.json                     # Stremio Addon Manifest
GET /:config/manifest.json             # Custom user configured manifest
GET /stream/:type/:id.json             # Stremio streams for movie / series (e.g. tt0111161)
GET /:config/stream/:type/:id.json     # Filtered streams based on user configuration
GET /nuvio-plugin.json                 # Nuvio Plugin Manifest (schema v1)
GET /api/nuvio/export                  # Downloadable plugin .json file
GET /api/health                        # Server health, uptime, and scraper stats
GET /api/test-stream?type=...&id=...   # Real-time stream resolution API
